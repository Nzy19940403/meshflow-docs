# 案例演示：基于循环依赖的自驱动系统

这个蜘蛛纸牌 Demo 展示了如何利用 `useEntangle` 的**循环依赖**特性，构建一个具备自执行能力的逻辑网络。

不同于传统的命令式编程，这个世界的物理规则仅由两条“纠缠场”定义：

1. **自驱动发牌**：发牌意图与牌堆互为因果。只要发牌未完成，意图节点与牌堆节点就会通过反馈环路产生震荡，驱动发牌动作一步步执行，直到达成逻辑平衡。
2. **自动翻牌逻辑**：当牌堆发生位移事实，会诱导旧牌堆的“坍缩”——如果旧牌堆顶层被遮盖的牌显露出来，它会根据力场规则自动翻开。

::: tip 为什么使用循环依赖？
在 MeshFlow 中，空间上的“循环”被解构为时间上的“演化”。这让我们可以像定义物理定律一样定义业务：你不需要写复杂的 `while` 循环或异步调度，逻辑节点自己会“咬合”在一起转动。
:::
